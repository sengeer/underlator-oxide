# ADR 0002: RAG — deferred

- **Статус:** accepted
- **Дата:** 2026-11-22
- **Связанные документы:** `docs/adr/0001-embedded-ollama-and-splash-dropped.md`, `openspec/specs/rag-ui-conservation/spec.md`

## Контекст

RAG (retrieval-augmented generation) не входит в MVP API `model` / `catalog` / `chat` и не является функцией текущего продукта. В Electron-версии базовый pipeline уже был пройден: загрузка документов, эмбеддинги, поиск и передача контекста в модель работали. Поэтому проблема не в отсутствии прототипа, а в качестве продукта: семантика поиска, chunking, мультимодальность и управление embedding-моделями требуют отдельного исследования и дизайна.

UI-заготовки RAG законсервированы: секция settings, attach/upload в чате, manage embedding models и `rag-ipc` остаются в дереве исходников с маркерами `TODO(rag)`, но не входят в MVP-путь.

## Решение

RAG **deferred**, а не «todo» и не пункт ближайшего backlog. Это отдельная исследовательская задача, которая не планируется к возврату в текущем этапе продукта.

Маркер `TODO(rag)` означает: «restoration not planned; requires new change + ADR update». Возврат RAG требует нового OpenSpec change, обновления этого ADR и отдельного research-цикла по семантике и мультимодальности. Консервированные модули, типы и константы RAG/embedding не удаляются.

## Последствия

- README и правила агентов не заявляют RAG как фичу и не обещают его возврат «позже».
- Консервированные RAG-модули и маркеры `TODO(rag)` остаются для истории и возможного будущего исследования.
- Любая работа над RAG начинается с нового change и обновления ADR, а не с раскомментирования заготовок.
- Архивные change сохраняют исторические формулировки без правок.

## Рассмотренные альтернативы

- **Пометить RAG как todo.** Отклонено: todo подразумевает запланированную работу с известным объёмом, а здесь нужен отдельный research-цикл.
- **Удалить консервированный RAG-код.** Отклонено: код документирует пройденный в Electron pipeline и снижает стоимость будущего исследования.
- **Включить RAG в MVP на текущем pipeline.** Отклонено: качество семантики и мультимодальности не подтверждено, а продукт позиционируется как конфиденциальный помощник по документам без непроверенных обещаний.
